## 요약 (한국어)

oh-my-grid는 **어떤 개인정보도 수집하지 않습니다.**

- **데이터 수집 없음** — 사용자 계정, 이름, 이메일, 위치, 사용 통계, 광고 식별자 등 어떤 데이터도 수집·전송하지 않습니다. 분석(analytics)·광고 SDK를 포함하지 않습니다.
- **모든 설정은 기기에만 저장** — 그리드·단축키·제외 앱 목록 등 앱 설정은 사용자의 Mac 로컬에만 저장되며, 외부로 전송되지 않습니다.
- **손쉬운 사용(접근성) 권한** — macOS 접근성 권한은 사용자가 실행한 창 이동·크기 조절에만 사용됩니다. 창의 내용은 읽지 않으며, 권한은 시스템 설정에서 언제든 철회할 수 있습니다.
- **네트워크 통신** — Mac App Store 버전은 네트워크 통신을 하지 않습니다. (GitHub 배포 버전에 한해 앱 업데이트 확인 목적으로 GitHub의 업데이트 정보 파일을 조회하며, 개인정보는 전송되지 않습니다.)

## Privacy Policy (English)

oh-my-grid is a macOS window management application developed by Golden Rabbit.

### Data collection

oh-my-grid does not collect, transmit, sell, or share personal data. It does not use analytics, advertising SDKs, tracking technologies, accounts, or remote servers.

### Window management and settings

The app needs the macOS Accessibility permission so that it can move and resize the windows you choose. It does not read the contents of your windows. Grid layouts, keyboard shortcuts, excluded apps, and other preferences are stored locally on your Mac.

### Network

The Mac App Store version performs no network communication. The GitHub-distributed version only checks a GitHub-hosted file for app updates; no personal data is sent.

### Permissions

- **Accessibility:** used only to move and resize windows when you trigger a snap, grid placement, or resize action.
- **User-selected file access:** used only when you pick applications to add to the exclusion list.

You can revoke permissions at any time in macOS System Settings.

### Children's privacy

oh-my-grid is not directed to children and does not collect personal information from anyone.

### Changes to this policy

If this policy changes, the updated version will be posted in this repository with a new effective date.
